
# BrightPath Digital Solutions

## Customer Support Operations Improvement Project

### Project Overview

This project focuses on investigating customer complaints, analysing recurring payment issues, documenting operational findings and recommending improvements to customer support and payment processes.

The project uses GitHub to manage tasks, document findings, track progress and organise operational deliverables.

### Business Objectives

- Identify recurring customer complaints.
- Analyse customer dissatisfaction and operational issues.
- Review reported payment discrepancies.
- Identify and verify potential duplicate subscription charges.
- Document refund coordination requirements.
- Recommend preventive controls and operational improvements.

### Project Scope

The project covers:

- Customer complaint analysis and prioritisation.
- Payment and transaction record review.
- Identification of potentially affected customers.
- Duplicate payment verification.
- Refund tracking and coordination.
- Preventive measures and process improvement recommendations.
- GitHub issue and project management.

### Project Deliverables

1. Customer Complaint Analysis.
2. Customer Complaint Priority Assessment.
3. Payment and Transaction Review.
4. Affected Customer Identification Report.
5. Duplicate Payment Verification Report.
6. Refund Tracking Register.
7. Duplicate Payment Prevention and Process Improvement Report.
